# Blood Donation Management System (BDMS)

## Overview
BDMS is a web-based system to manage blood donations, donors, requests, and donation campaigns. 

**Technologies:** PHP, MySQL, Bootstrap 5, HTML, CSS, JS

## Features
- **Admin Portal:** Manage donors, blood inventory, requests, and campaigns.
- **Donor Portal:** Register, view donation history, participate in campaigns, update profile.

## Installation
1. Import `bdms.sql` into MySQL.
2. Configure `db.php` with your database credentials.
3. Run the project on a local server (XAMPP/WAMP).

## Users
- **Admin:** Can manage all data and view analytics.
- **Donor:** Can view campaigns, history, and update profile.
